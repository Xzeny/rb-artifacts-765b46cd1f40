What's in the kit

The kit is what a YouTube creator needs to film a Rebind video. Paid, affiliate, and sponsorship terms are left out on purpose. Creators record their own captures; Rebind does not supply footage. The summaries below describe kit v1.1.

SectionWhat it covers
1. The pitch“Command, don’t configure.” One-line description: a free, programmable input layer for Windows and macOS; Luau scripts for keyboard and mouse; Rebind Link when real USB hardware output is needed. Positioning: a device-macro, automation, and accessibility multitool for your PC or Mac. Supported today: Windows 10/11 64-bit and macOS 13+ on Apple Silicon.
2. What it isLuau scripting (including the one-line Caps Lock to Escape remap), software mode (free, no hardware, no account for local scripts), and hardware mode (Rebind Link or BYOH). Controllers only in hardware mode, with a Rebind Link or BYOH whose USB profile includes a joypad. The default USB profile is keyboard and mouse only [D2, Hardware Setup].
3. Demo-ready video ideasSeven ideas, each documented today. Start every demo with the kill switch: Left Ctrl + Left Alt + K (Mac: Left Control + Left Option + K). P1 and P2 (productivity); G2, “Your controller as a desktop remote,” under the heading “Controller remaps (desktop demo, no game on screen)”; A1 (accessibility recipes; “scripts, not a medical treatment”); E1 (Excel-only layer); S1 and S2 (streaming / overlays). G1 was cut. G2 is hardware mode only: a Rebind Link, or BYOH with a joypad USB profile. Bumper-to-tab is an example script the creator writes, not a built-in mapping [D3, Controllers recipe].
4. Verified factsPlatforms, the mobile line, retail prices (app free; Link $140; BYOH $90; Pro $9/month or $72/year), install commands, scripting including bring-to-front (rb.app.activate, D1), mode limits. 5. Talking points and claims fenceLines creators can say, a “use both” posture, disclosure for any free unit or paid content, and a say / don’t-say table. No affiliate rates or budgets.
6. Assets and capture tipsLogo (provisional Inconsolata lockup, 6 mm print minimum), all six hero-frame mock-ups including frame 03, six placeholder thumbnail templates, B-roll shot list, and capture hygiene. Hero frames 01–05 must keep the caption “Simulated UI / animated mock-up.”

Nothing is allocated or approved to ship.” Contact email is still [CONTACT EMAIL TBD]. R4, restoring the older “US or Canada” clause, is held for you (Decision 2).

1. App launching

On Nov 13 you said “Yes, Rebind can launch apps; show it.” The public SDK docs, as read on Nov 13, only document rb.app.activate, which brings an already-running app forward. There is no cookbook recipe that starts a closed app. Comms notes an unpublished / thinly documented call, rb.system.exec_detached (needs the exec permission). That call is mentioned on the Stream Deck compare page and the platforms page, but no docs.rebind.gg recipe walks through it, so the kit does not claim cold launch.

Frame 03 in v1.1 matches bring-to-front: “the app must already be running; this does not start it.” A “launch” decision would still need a published docs recipe and a new or revised frame.

The old “D1, confirmed by Dean” label has been corrected in kit v1.1. D1 is now tagged as docs-sourced (SDK reference). You confirmed launching, not bring-to-front. Whether the kit may say “launch” is still this decision.

Recommendation: If Product publishes a short docs recipe for starting an app, the kit can say “launch,” and frame 03 plus B13 can be redrawn for that wording. Until a recipe exists that a creator can film, keep the bring-to-front wording — which the v1.2 assets and kit v1.1 already show — so the kit does not outrun a documented demo.
