1. Bottom line for the CEO

  • Buy no production breadth before proving the action. The smallest useful master shows the real input, named script and visible result in the same take. Existing pages and animated keycaps are not substitutes [Inference; S05,S-Growth].
  • Specify all shared space types, but do not build ads. Communities, search/discovery, creators, paid surfaces, product-led loops, events/IRL and owned media need different wrappers around the same honest proof [Verified-source: taxonomy S-Strategy §2; wrapper recommendation: Inference].
  • Start with Keystroke Overlay evidence. The strategy selects it as the leading visible-output beachhead. Current listing/platform/capture conditions still need verification before any recording [Verified-source: S-Strategy §4,S-Growth §2].
  • Separate installation from activation. A marketplace demo needs the free-app step and a separate script-install/permissions step, then the named script doing the visible thing. A welcome tour is not activation [Verified-source: S-Growth §§1–3].
  • Make mute and paste falsifiable. Show the destination app's actual state or resulting text, not a decorative icon. Mute must never be presented as confirmed by a shortcut alone [Inference; source limitations S-Strategy §1,S-Growth §2,S-SEO §2].
  • Accessibility is a release gate, not an aesthetic. Corrected captions, descriptive narration/text alternatives, measured contrast, non-colour cues and pausable motion must be specified before editing. No conformance claim follows from this memo [Inference; W-A11Y].

3. Shared capture and proof grammar

Capture contract [Inference]

Record a clean supported desktop profile: Windows 10/11 64-bit or macOS 13+ Apple Silicon [Verified-source: S02]. Log actual app/build, script id/version, keyboard layout, source listing, permissions, capture method, starting state and reset instructions. Avoid “latest” unless checked that day. Keep notifications, accounts, private files, personal clipboard history and unrelated tabs out of frame. Use seeded demonstration data; clear rights for any voice, likeness, software artwork or third-party footage.

Recommended reusable master: 1920×1080, 16:9, 30 fps [Inference], with a legible region-of-interest capture rather than an unreadable full desktop. Preserve an uncut proof take and a separate edited derivative. Any acceleration, omitted install wait or reconstruction is labelled; do not fake response latency or benchmark speed. Runtime follows the action, including readable holds, not an alleged platform retention rule [Inference].
