1. Bottom line for the CEO

  • Keep the hold. Buying reach would amplify an unproven activation path and an attribution break, not an established acquisition system [Inference; S02,S05,S06,S09]. This inventory is not permission to advertise.
  • Research intent before buying scale. Job-led Search and desktop tutorial discovery are the strongest later hypotheses; Reddit is a possible amplifier, not a workaround for organic removals [Inference; S-Strategy,S-SEO,S-Comms].
  • Lead with a visible script result. Keystroke Overlay is the clearest first proof candidate. Installing Rebind and installing the script are separate actions; activation is the script doing the visible thing, not app install or welcome tour [Verified-source: S-Strategy §4,S-Growth §§1–3]. Actual execution still needs Testing.
  • Later scope: US+CA English, desktop only. A computer device is not proof of supported OS/chip. Newsletters unable to enforce this scope are ineligible, not exceptions hidden in the media plan [Inference; eligibility: S02].
  • Hard-exclude MouseReview, Elgato and Cronus/XIM/FPS-aim. Historical optional rows and creator suggestions do not overrule this scope. TypeTation receives no traffic [Inference: planning constraint; S02,S06,S-Strategy].
  • No public fixed newsletter fee was verified. Console and Changelog publish sponsorship products but no rates on the fetched pages. The attempted kbd.news advertising URL returned editorial content, not a usable rate card [Verified-web: W06–W08]. “Contact us” is not a price.
