  • [Inference] means a conversion-path design, recommendation, likely friction or prioritization. Nothing is claimed to outperform anything else.

Bottom line for the CEO

  • Keep one honest install destination: https://www.rebind.gg/install. A job-shaped context page may precede it later, but no draft URL is treated as live. Keep the exact Marketplace listing available across the handoff. [Verified-source: G, L; Inference: path rule]
  • The conversion chain has distinct commitments: understand the job → install Rebind → separately install the named script → see it work. App download, copied command, app launch, script install and useful activation are not interchangeable. [Verified-source: G, L]
  • The largest likely loss is intent mismatch, not button color. A generic runtime install page cannot by itself promise to deliver the script someone saw. Make the separate script step and expected result obvious before download. This is a hypothesis, not a measured largest drop-off. [Inference, grounded in G]
  • Qualification is part of conversion quality. Supported desktop means Windows 10/11 64-bit or macOS 13+ Apple Silicon only; Linux, Intel Mac and a phone cannot complete this desktop app journey. Turning away unsupported traffic is the honest result. [Verified-source: P; Inference: qualification]
  • No source-attributed install economics today. passRefToInstaller=false; ref stops at download-start. Source-designed events are not proof of backend collection. CPI, cost per activation and variant-to-activation uplift are unknown, not estimates to fill in. [Verified-source: G, L, H]
  • Holds override every attractive path. No TypeTation campaign destinations; no organic Reddit; no paid activation. Researching a path is not permission to use it. [Verified-source: S, C, G]

Canonical path and the destination contract

Space-specific attention, with disclosure where required
  → one job / truthful evidence / eligibility and limits
  → https://www.rebind.gg/install
  → install Rebind on an eligible desktop
  → open or manually find the exact named Marketplace listing
  → review conditions and requested permissions
  → separately install the script
  → perform its first action and see the intended result

[Verified-source: G] The separate Marketplace install and visible result define the core path. [Inference] The context, recovery and message-match treatments are proposed CRO specifications, not shipped behavior.

A person discovering a script in Marketplace is already on the listing. The path then goes listing → /install if the app is absent → back to the same listing → separate script install. An existing app user may not need the app-install step; do not force a redundant installer download to manufacture a conversion. Current app detection, return links and deep-link support are unknown. [Verified-source: G; Inference: branching; Unknown: routing implementation]
